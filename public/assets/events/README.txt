Event flyers go here. To attach one to a show:
  1. Export the flyer (JPEG or WebP, ~1080px wide is plenty for web).
  2. Save it here, e.g. karunna-tulum.jpg
  3. In src/data/shows.ts, set that show's `flyer` to "/assets/events/karunna-tulum.jpg"

Expected files (currently missing — pages render fine without them):
  - karunna-tulum.jpg      -> show "karunna-tulum-ago-2026"
  - rockstar-leon.jpg      -> show "rockstar-burger-leon-ago-2026"
  - rockstar-fest.jpg      -> show "rockstar-fest-leon-oct-2026"

The flyer, when present, is also used as the event's social-share (OG) image.
